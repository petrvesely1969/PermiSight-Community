# Version notes / Poznámky k verzím

These notes describe product versions, not a promise of availability in each
distribution channel. See [Downloads](DOWNLOADS.md) for current channel status.

## 1.0.1 — Store submission

- Local read-only inspection of supported AI applications, model files and
  editor/CLI/browser components on Windows and macOS.
- Separate views for applications, models and tools, with technical evidence
  and visible limits on the check.
- Saved results, optional report submission after preview and consent, and
  manual signed detection-catalog updates.
- Personal edition without sign-in or in-app purchases; English and Czech UI.
- Mac submission build 20 includes the corrected privacy manifest for optional
  report submission. Windows package version is 1.0.1.0, application build 6507.

Store submission is separate from approval, public release and installation
from a Store. This entry does not claim that every listed installation path,
product version or nonstandard port has been physically tested.

## Česky — 1.0.1

Místní kontrola podporovaných aplikací, modelů a doplňků na Windows a Macu;
samostatné přehledy, podklady nálezů a pravdivé omezení kontroly. Uložení
výsledků, dobrovolné reporty po náhledu a souhlasu a ruční aktualizace
podepsaného katalogu. Osobní edice bez přihlášení a nákupů v aplikaci,
české a anglické rozhraní.

Mac má v podání sestavení 20 s opraveným prohlášením soukromí. Windows Store
balíček má verzi 1.0.1.0, sestavení aplikace 6507. Podání, schválení, veřejné
vydání a skutečná instalace z obchodu jsou samostatné kroky; aktuální stav je
uvedený na stránce stažení.
