# Support / Podpora

[Official support](https://www.permisight.com/support/) ·
[Privacy information](https://www.permisight.com/privacy/)

Public contact: **permisight@bsaudit.cz**, **+420 910 124 430**.

## Choose a route

- **Bug or missing detection:** use the corresponding Issue form. Give the
  application version/build, operating system, tool version and short steps.
  A catalog revision is useful if you know it; it is fine to say unknown.
- **Question or idea:** use Discussions. English and Czech are welcome.
- **A supported scan report:** use the report action in PermiSight, review the
  preview and recipient, and decide whether to consent. The scan does not send
  results automatically.
- **Confidential or suspected security issue:** contact support privately with
  a minimal description first. Do not post exploitable details, personal data,
  credentials, raw reports or attachments in a public Issue or Discussion.

Public posts can be read and copied by anyone. Remove names, private file paths,
email addresses, identifiers, tokens and confidential configuration from any
example or screenshot. Do not upload complete scan exports here. A public post
is not the private in-app report channel.

## Česky

- Chybu nebo nerozpoznaný nástroj zadejte příslušným formulářem v Issues.
  Stačí verze a sestavení PermiSightu, operační systém, verze nástroje
  a krátký postup. Neznámou verzi katalogu nemusíte dohledávat.
- Dotazy a nápady patří do Discussions. Pište klidně česky.
- Podporovaný report posílejte dobrovolně z aplikace po náhledu a souhlasu.
  Samotná kontrola výsledky automaticky neodesílá.
- Důvěrný problém nebo podezření na bezpečnostní chybu nejprve stručně
  popište soukromě podpoře. Do veřejného příspěvku nevkládejte celý report,
  osobní údaje, přístupové údaje ani přílohy s důvěrným obsahem.

Veřejné příspěvky může kdokoli přečíst a zkopírovat. Ze všech příkladů a snímků
odstraňte osobní cesty, jména, e-maily, identifikátory a tajné části nastavení.
Zveřejnění na GitHubu není soukromé odeslání reportu výrobci.
