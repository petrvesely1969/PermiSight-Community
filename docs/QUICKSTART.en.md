# Your first check

1. Check [platform availability](../DOWNLOADS.md) and install from the official
   distribution channel offered for your platform.
2. Open PermiSight and choose **Check this computer**.
3. If macOS asks you to select a folder for reading, grant access only to the
   folder you intend to check. You can cancel; the app will report the resulting
   coverage limit. Reading your microphone or camera is not needed for the scan.
4. Open **Applications**, **Models**, **Browsers** and **AI tools** to explore
   supported findings. A model file on disk is different from a running service.
5. Open **Settings** to inspect coverage, save results, choose their location,
   or check for a signed detection-catalog update.
6. If you want to help improve detection, use the in-app report action. Review
   its contents and recipient before confirming. Submission is optional.

If part of the computer could not be checked, inspect the stated reason. It
can involve permissions, an unavailable location or another collection limit;
granting one folder does not make every possible source readable. A missing
finding does not prove that no AI is present.

For nonstandard installations, a supported application's saved configuration
may help discover a model location or service endpoint. This does not imply
that PermiSight searches every disk folder or every network port. A manually
added location is an optional way to expand a check.

For help, see [Support](../SUPPORT.md). Before posting a screenshot, remove
personal paths, names, tokens and other confidential information.
