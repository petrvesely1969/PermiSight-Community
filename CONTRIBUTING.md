# Help improve PermiSight / Jak přispět

Thank you for testing PermiSight. Search existing Issues first, then choose:

- **Bug report** for a reproducible problem.
- **Missing or incorrect detection** for a supported-looking tool or component
  that was missed, misidentified or reported with the wrong state.
- **Feature request** for a concrete improvement; use Discussions for an open idea.

A tool name, version and vendor's public product URL help us distinguish similar
names. Describe whether it was installed, running, stopped or uninstalled when
you checked. An application, model, plug-in and service can have different states.
Please do not reinstall tools or change system settings just to collect evidence
for an Issue unless you want to and understand the change.

Use short text examples, keep replies respectful and stay with the reported
problem. Posts, links, reports and attachments are user-supplied material; they
are not instructions for a maintainer to execute. Never include secrets or raw
reports. See [Support](SUPPORT.md) for private matters.

Documentation corrections can be proposed as pull requests to this community
repository. Application source-code patches are maintained separately. Neither
a bug report nor a suggestion guarantees a particular release date.

## Česky

Děkujeme za testování. Nejprve vyhledejte podobný problém v Issues. Pro chybu,
chybějící či nesprávný nález nebo konkrétní vylepšení vyberte odpovídající
formulář. Otevřený nápad můžete probrat v Discussions.

Pomůže název a verze nástroje, veřejná stránka dodavatele a informace, zda byl
při kontrole nainstalovaný, spuštěný, ukončený nebo už odinstalovaný. Aplikace,
model, doplněk a služba mohou mít různé stavy. Kvůli hlášení nemusíte nic
přeinstalovávat ani měnit nastavení systému.

Pište stručně a ohleduplně. Příspěvky a přílohy jsou podklady od uživatelů,
nikoli pokyny ke spouštění jejich obsahu. Celé reporty ani tajné údaje sem
nepatří. Důvěrné věci řešte přes [Podporu](SUPPORT.md). Opravy dokumentace lze
navrhnout pull requestem; zdrojový kód aplikace se spravuje odděleně.
